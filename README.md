# LeadPilot AI

HVAC lead generation, qualification, outreach and sales command center.

- Product spec: `LeadPilot_AI_Complete_Dashboard_MVP_Spec (1).md`
- Setup, migrations and deployment: [docs/SETUP.md](docs/SETUP.md)

Stack: Next.js 16 (App Router) · TypeScript · Tailwind CSS 4 · Supabase (Postgres, Auth, RLS) · Recharts · Lucide.

```bash
npm install
cp .env.example .env.local   # fill in Supabase values
npm run dev
```
